# Mapa de materias: Ingeniería Química (UTN FRBA) e Ingeniería Nuclear (UTN FRC)

Página estática de solo lectura con dos pestañas:

- **Química · FRBA**: materias del Plan 2023 (Ord. C.S. 1875) con su situación: aprobada o regularizada.
- **Nuclear · FRC**: materias del Plan 2027 (Ord. C.S. 2231/2026) y cuáles coinciden por nombre con materias ya aprobadas en Química.

Todo está en `index.html`, sin dependencias ni proceso de compilación. Se publica con GitHub Pages desde la rama `main`, carpeta raíz.
